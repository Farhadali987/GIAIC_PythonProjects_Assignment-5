# Production Checklist

- [ ] Frontend builds successfully (Next.js 15).
- [ ] Backend starts successfully (FastAPI).
- [ ] Database migrations are executed.
- [ ] Clerk authentication is configured and working.
- [ ] AI services (Qwen/Gemini) are correctly authenticated.
- [ ] External API connections (Weather, Maps) are healthy.
- [ ] All unit/integration tests pass.
- [ ] CI/CD pipeline is active on GitHub.
- [ ] Docker images build and start correctly.
- [ ] Production environment variables are set.
- [ ] Monitoring and logging are enabled.
